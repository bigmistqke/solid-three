# Installation

## Prerequisites

Ensure that you have `solid-js` installed in your environment, as it is a peer dependency of `solid-three`.

## Package Managers

Install `solid-three` and `three` using your preferred package manager:

### npm
```bash
npm install solid-three three
```

### pnpm
```bash
pnpm install solid-three three
```

### yarn
```bash
yarn add solid-three three
```

## TypeScript Support

`solid-three` is written in TypeScript and provides full type definitions out of the box. No additional type packages are required.

## Next Steps

Once installed, you can start building your 3D scenes. Check out the [Quick Start](/quick-start) guide to learn the basics.

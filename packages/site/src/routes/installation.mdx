# Installation

## Prerequisites

> **Peer Dependency**: Ensure that you have `solid-js` installed in your environment, as it is a peer dependency of `solid-three`.

## Package Managers

Install `solid-three` and `three` using your preferred package manager:

```bash tab title="npm"
npm install solid-three three
```

```bash tab title="pnpm"
pnpm install solid-three three
```

```bash tab title="yarn"
yarn add solid-three three
```

## TypeScript Support

> **TypeScript Ready**: `solid-three` is written in TypeScript and provides full type definitions out of the box. No additional type packages are required.

## Next Steps

Once installed, you can start building your 3D scenes. Check out the [Quick Start](/quick-start) guide to learn the basics.

# Metadata Utilities

These utilities help manage metadata associated with THREE.js objects in solid-three.

> **Advanced Usage**: These utilities are primarily for debugging, library development, and advanced use cases.

> **Internal System**: solid-three uses metadata internally to track component relationships and manage lifecycles.

## API Reference

| Function | Type | Description |
|----------|------|-------------|
| **getMeta** | `(object: Object3D) => any` | Get metadata for a THREE.js object |
| **hasMeta** | `(object: Object3D) => boolean` | Check if object has metadata |
| **meta** | `WeakMap` | Internal metadata storage |
| **$S3C** | `Symbol` | Internal symbol for component metadata |

## Usage Patterns

```tsx tab title="Debugging Objects"
import { getMeta, hasMeta } from "solid-three"

function DebugInspector() {
  let meshRef
  
  const inspectMesh = () => {
    const mesh = meshRef
    
    if (hasMeta(mesh)) {
      const metadata = getMeta(mesh)
      console.log("Object metadata:", metadata)
      console.log("Component type:", metadata?.[$S3C]?.type)
    } else {
      console.log("No solid-three metadata found")
    }
  }
  
  return (
    <>
      <T.Mesh ref={meshRef}>
        <T.BoxGeometry />
        <T.MeshBasicMaterial />
      </T.Mesh>
      <button onClick={inspectMesh}>Inspect Object</button>
    </>
  )
}
```

```tsx tab title="Custom Metadata"
// Add your own metadata to objects
function CustomMetadata() {
  let objectRef
  
  onMount(() => {
    const object = objectRef
    if (object) {
      const existingMeta = getMeta(object) || {}
      meta.set(object, {
        ...existingMeta,
        customId: "my-object-123",
        createdAt: Date.now(),
        userData: { type: "interactive" }
      })
    }
  })
  
  return <T.Group ref={objectRef}>{/* children */}</T.Group>
}
```

```tsx tab title="Scene Analysis"
// Analyze entire scene metadata
function SceneAnalyzer() {
  const three = useThree()
  
  const analyzeScene = () => {
    three.scene.traverse((object) => {
      if (hasMeta(object)) {
        const metadata = getMeta(object)
        console.log(`${object.name || object.id}:`, metadata)
      }
    })
  }
  
  return (
    <button onClick={analyzeScene}>
      Analyze Scene Metadata
    </button>
  )
}
```

## Advanced Usage

### Custom Metadata

```tsx
function CustomMetadata() {
  let objectRef
  
  onMount(() => {
    // Add custom metadata to an object
    const object = objectRef
    if (object) {
      const existingMeta = getMeta(object) || {}
      meta.set(object, {
        ...existingMeta,
        customId: "my-object-123",
        createdAt: Date.now(),

    }
  })
  
  return (
    <T.Group ref={objectRef}>
      {/* children */}
    </T.Group>
  )
}
```

### Debug Information

```tsx
function DebugScene() {
  const inspectAll = () => {
    const scene = document.querySelector('canvas')
    // Traverse all objects and inspect metadata
    scene?.traverse?.((object) => {
      if (hasMeta(object)) {
        const metadata = getMeta(object)
        console.log(`Object ${object.name || object.id}:`, metadata)
      }
    })
  }
  
  return (
    <>
      <T.Mesh name="debug-cube">
        <T.BoxGeometry />
        <T.MeshBasicMaterial />
      </T.Mesh>
      
      <button onClick={inspectAll}>
        Debug All Objects
      </button>
    </>
  )
}
```

## Internal Usage

These utilities are primarily used internally by solid-three for:
- Tracking component relationships
- Managing object lifecycles
- Debugging and development tools
- Integration with SolidJS reactivity

```tsx
// Internal usage example (for library developers)
function createCustomComponent() {
  const object = new THREE.Object3D()
  
  // solid-three internally stores metadata like this:
  meta.set(object, {
    [$S3C]: {
      type: 'CustomComponent',
      props: {},
      owner: getOwner() // SolidJS owner context
    }
  })
  
  return object
}
```

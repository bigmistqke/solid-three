# Raycasters

solid-three provides custom raycaster implementations that handle pointer tracking internally. All raycasters extend THREE.Raycaster and implement the `EventRaycaster` interface.

## EventRaycaster Interface

```typescript
interface EventRaycaster extends THREE.Raycaster {
  update(event: PointerEvent | MouseEvent | WheelEvent, context: Context): void
}
```

The `update()` method is automatically called before intersection testing for:
- Mouse events: `click`, `mousedown`, `mouseup`, `mousemove`, `contextmenu`, `dblclick`
- Pointer events: `pointerdown`, `pointerup`, `pointermove`
- Wheel events: `wheel`

## Built-in Raycasters

### CursorRaycaster

The default raycaster that tracks the cursor position:

```tsx
import { Canvas } from "solid-three"
import { CursorRaycaster } from "solid-three"

const App = () => {
  const raycaster = new CursorRaycaster()
  
  // CursorRaycaster is used by default, but you can explicitly set it:
  return <Canvas defaultRaycaster={raycaster}>{/* Your scene */}</Canvas>
}
```

### CenterRaycaster

A raycaster that always casts from the center of the screen, useful for first-person games or VR applications:

```tsx
import { Canvas } from "solid-three"
import { CenterRaycaster } from "solid-three"

const App = () => {
  const raycaster = new CenterRaycaster()
  
  return (
    <Canvas defaultRaycaster={raycaster}>
      {/* Crosshair UI */}
      <div style={{
        position: 'absolute',
        top: '50%',
        left: '50%',
        transform: 'translate(-50%, -50%)',
      }}>
        +
      </div>
      
      {/* 3D Scene */}
      <T.Mesh onClick={() => console.log("Hit!")}>
        <T.BoxGeometry />
        <T.MeshBasicMaterial />
      </T.Mesh>
    </Canvas>
  )
}
```

## Creating Custom Raycasters

```tsx
import { Raycaster, Vector2 } from "three"
import type { EventRaycaster, Context } from "solid-three"

class CustomRaycaster extends Raycaster implements EventRaycaster {
  constructor() {
    super()
    // Initialize your custom raycaster
  }

  update(event: PointerEvent | MouseEvent | WheelEvent, context: Context) {
    const pointer = new Vector2()
    
    // Calculate normalized device coordinates based on your custom logic
    
    // Example: Apply custom transformation to pointer coordinates
    pointer.x = ((event.offsetX / context.bounds.width) * 2 - 1) * 0.5
    pointer.y = (-(event.offsetY / context.bounds.height) * 2 + 1) * 0.5
    
    // Update the raycaster with the transformed coordinates
    this.setFromCamera(pointer, context.camera)
  }
}

// Usage
const App = () => {
  const raycaster = new CustomRaycaster()
  
  return <Canvas defaultRaycaster={raycaster}>{/* Your scene */}</Canvas>
}
```

## Advanced Examples

### Offset Raycaster

A raycaster with a configurable offset from the cursor:

```tsx
class OffsetRaycaster extends Raycaster implements EventRaycaster {
  constructor(private offsetX = 0, private offsetY = 0) {
    super()
  }

  update(event: PointerEvent | MouseEvent | WheelEvent, context: Context) {
    const pointer = new Vector2()
    
    // Apply offset to pointer coordinates
    pointer.x = ((event.offsetX + this.offsetX) / context.bounds.width) * 2 - 1
    pointer.y = -((event.offsetY + this.offsetY) / context.bounds.height) * 2 + 1
    
    this.setFromCamera(pointer, context.camera)
  }
}

// Usage: Raycast 50px to the right of cursor
const raycaster = new OffsetRaycaster(50, 0)
```

### Restricted Area Raycaster

Only raycast within a specific screen area:

```tsx
class RestrictedRaycaster extends Raycaster implements EventRaycaster {
  constructor(
    private minX: number,
    private minY: number,
    private maxX: number,
    private maxY: number
  ) {
    super()
  }

  update(event: PointerEvent | MouseEvent | WheelEvent, context: Context) {
    // Check if pointer is within restricted area
    const x = event.offsetX / context.bounds.width
    const y = event.offsetY / context.bounds.height
    
    if (x < this.minX || x > this.maxX || y < this.minY || y > this.maxY) {
      // Set ray to point nowhere (no intersections)
      this.ray.origin.set(0, 0, 0)
      this.ray.direction.set(0, 0, 0)
      return
    }
    
    // Normal raycasting within area
    const pointer = new Vector2(
      x * 2 - 1,
      -(y * 2 - 1)
    )
    
    this.setFromCamera(pointer, context.camera)
  }
}

// Only raycast in center 50% of screen
const raycaster = new RestrictedRaycaster(0.25, 0.25, 0.75, 0.75)
```

### Multi-Sample Raycaster

Cast multiple rays for anti-aliased picking:

```tsx
class MultiSampleRaycaster extends Raycaster implements EventRaycaster {
  private samples = [
    new Vector2(0, 0),
    new Vector2(-0.5, -0.5),
    new Vector2(0.5, -0.5),
    new Vector2(-0.5, 0.5),
    new Vector2(0.5, 0.5),
  ]
  
  update(event: PointerEvent | MouseEvent | WheelEvent, context: Context) {
    const baseX = (event.offsetX / context.bounds.width) * 2 - 1
    const baseY = -(event.offsetY / context.bounds.height) * 2 + 1
    
    // Use the center sample for the main ray
    this.setFromCamera(new Vector2(baseX, baseY), context.camera)
    
    // You could store additional rays for custom intersection logic
    // this.additionalRays = this.samples.map(offset => ...)
  }
}
```

## Performance Tips

1. **Reuse Raycasters**: Create raycaster instances once and reuse them
2. **Limit Ray Distance**: Set `far` property to limit ray length
3. **Use Layers**: Utilize THREE.js layers to exclude objects from raycasting
4. **Custom Logic**: Implement early exits in `update()` when appropriate

```tsx
// Optimized raycaster setup
const raycaster = new CursorRaycaster()
raycaster.far = 100 // Only check first 100 units
raycaster.layers.set(1) // Only raycast layer 1
```

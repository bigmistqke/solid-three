# Portal

The Portal component allows you to place children outside the regular scene graph while maintaining reactive updates. This is useful for rendering objects into different scenes or bypassing the normal parent-child relationships.

> **When to Use Portal**: Use when you need to bypass normal scene hierarchy, render UI overlays, or manage complex multi-scene compositions.

> **Performance**: Portals maintain reactivity but can affect render order. Use sparingly for optimal performance.

## Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| **element** | `Object3D \| Meta<Object3D>` | root scene | Target object to render children into |
| **children** | `JSX.Element` | - | Elements to render in the portal |
| **onUpdate** | `(value: T) => void` | - | Callback when portal element updates |

## Decision Matrix

| Use Case | Portal | Normal Hierarchy |
|----------|--------|------------------|
| **UI Overlays** | ✅ Best choice | ❌ Inherits transforms |
| **Multi-scene Setup** | ✅ Best choice | ❌ Not possible |
| **Bypass Transforms** | ✅ Best choice | ❌ Inherits parent |
| **Simple Grouping** | ❌ Overkill | ✅ Better performance |
| **Normal 3D Objects** | ❌ Unnecessary | ✅ Recommended |

## Common Use Cases

```tsx tab title="UI Overlays"
// Perfect for HUD elements that shouldn't inherit 3D transforms
function UIOverlay() {
  const uiScene = new THREE.Scene()
  const uiCamera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1)
  
  return (
    <>
      {/* Main 3D scene */}
      <T.Mesh>
        <T.BoxGeometry />
        <T.MeshStandardMaterial />
      </T.Mesh>
      
      {/* UI rendered in separate scene - no 3D transforms */}
      <Portal element={uiScene}>
        <T.Sprite position={[0.8, 0.8, 0]}>
          <T.SpriteMaterial color="white" />
        </T.Sprite>
      </Portal>
    </>
  )
}
```

```tsx tab title="Bypass Hierarchy"
// Escape parent transforms when needed
function ComplexScene() {
  const specialGroup = new THREE.Group()
  
  return (
    <T.Group rotation-y={Math.PI / 4}>
      <T.Mesh>
        <T.BoxGeometry />
        <T.MeshBasicMaterial />
      </T.Mesh>
      
      {/* This mesh won't inherit the parent's rotation */}
      <Portal element={specialGroup}>
        <T.Mesh position={[2, 0, 0]}>
          <T.SphereGeometry />
          <T.MeshBasicMaterial color="red" />
        </T.Mesh>
      </Portal>
    </T.Group>
  )
}
```

```tsx tab title="Multi-Scene Setup"
// Complex rendering pipelines with multiple scenes
function MultiSceneSetup() {
  const backgroundScene = new THREE.Scene()
  const foregroundScene = new THREE.Scene()
  
  return (
    <>
      {/* Background layer */}
      <Portal element={backgroundScene}>
        <T.Mesh scale={10}>
          <T.PlaneGeometry />
          <T.MeshBasicMaterial color="skyblue" />
        </T.Mesh>
      </Portal>
      
      {/* Main scene content */}
      <T.Group>
        {/* Primary 3D content here */}
      </T.Group>
      
      {/* Foreground overlay */}
      <Portal element={foregroundScene}>
        <T.Mesh position={[0, 0, 5]}>
          <T.PlaneGeometry args={[2, 0.5]} />
          <T.MeshBasicMaterial transparent opacity={0.8} />
        </T.Mesh>
      </Portal>
    </>
  )
}
```

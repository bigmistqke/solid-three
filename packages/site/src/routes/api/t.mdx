# T Components

The `T` namespace contains components that wrap `three.js` objects, allowing you to insert them into your scene declaratively. You create the namespace using the `createT()` factory function.

> **Best for Applications**: T namespace provides excellent TypeScript support and component-like syntax. For libraries, consider using Entity components instead.

> **Bundle Size**: Use tree-shaking approach for production builds to minimize bundle size.

## Creating the T Namespace

```tsx tab title="Complete Import (Development)"
import { createT } from "solid-three"
import * as THREE from "three"

// Create T namespace with all three.js objects
const T = createT(THREE)

// Now you can use T components with full IntelliSense
<T.Mesh>
  <T.BoxGeometry args={[1, 1, 1]} />
  <T.MeshBasicMaterial color="hotpink" />
</T.Mesh>
```

```tsx tab title="Tree-Shaking (Production)"
import { createT } from "solid-three"
import { Mesh, BoxGeometry, MeshBasicMaterial } from "three"

// Create T namespace with only what you need
const T = createT({ Mesh, BoxGeometry, MeshBasicMaterial })

// Smaller bundle size, same functionality
<T.Mesh>
  <T.BoxGeometry args={[1, 1, 1]} />
  <T.MeshBasicMaterial color="hotpink" />
</T.Mesh>
```

```tsx tab title="Multiple Namespaces"
// Split by feature for lazy loading
const T = createT({ Mesh, BoxGeometry, MeshBasicMaterial })
const TLights = createT({ AmbientLight, DirectionalLight, PointLight })
const TPost = createT(await import("three/examples/jsm/postprocessing"))

// Use different namespaces as needed
<Canvas>
  <TLights.AmbientLight intensity={0.5} />
  <T.Mesh>
    <T.BoxGeometry />
    <T.MeshBasicMaterial />
  </T.Mesh>
</Canvas>
```

## Recommended Usage Patterns

> **Architecture Decision**: Choose between centralized T namespace for apps vs Entity components for libraries.

| Use Case | Recommended Approach | Why |
|----------|---------------------|-----|
| **Applications** | Single shared T namespace | Better DX, IntelliSense, consistency |
| **Libraries** | Entity components | No namespace requirement for consumers |
| **Large Apps** | Multiple T namespaces | Code splitting, lazy loading |
| **Prototyping** | Complete import | Faster development, all features available |

### Application Pattern
Create a single shared T namespace:

```tsx
// lib/three.ts
import { createT } from "solid-three"
import * as THREE from "three"

export const T = createT(THREE)

// components/Scene.tsx
import { T } from "../lib/three"

export function Scene() {
  return (
    <T.Mesh>
      <T.BoxGeometry />
      <T.MeshBasicMaterial />
    </T.Mesh>
  )
}
```

### Library Pattern
For libraries, prefer Entity components to avoid namespace requirements:

```tsx
// Don't force consumers to create T namespace
export function MyLibraryComponent(props) {
  return (
    <Entity from={Mesh} {...props}>
      <Entity from={BoxGeometry} args={[1, 1, 1]} />
      <Entity from={MeshBasicMaterial} color="red" />
    </Entity>
  )
}
```

## Props and Arguments

> **Direct Mapping**: T component props map directly to THREE.js object properties with enhanced syntax for common patterns.

```tsx
<T.Mesh
  position={[0, 1, 0]}        // THREE.Vector3 or array
  rotation-y={Math.PI / 4}    // Direct property access
  scale={2}                   // Uniform scaling
>
  <T.BoxGeometry args={[1, 1, 1, 4, 4, 4]} />  // Constructor arguments
  <T.MeshStandardMaterial 
    color="orange"           // Color name, hex, or THREE.Color
    roughness={0.5} 
    metalness={0.8}
  />
</T.Mesh>
```

### Prop Patterns

| Pattern | Example | THREE.js Equivalent |
|---------|---------|--------------------|
| **Direct props** | `color="red"` | `material.color.set("red")` |
| **Array notation** | `position={[1, 2, 3]}` | `object.position.set(1, 2, 3)` |
| **Hyphen notation** | `rotation-y={Math.PI}` | `object.rotation.y = Math.PI` |
| **Constructor args** | `args={[1, 2, 3]}` | `new Constructor(1, 2, 3)` |

## TypeScript Support

> **Full IntelliSense**: T components provide complete type safety and autocomplete for all THREE.js properties and constructor arguments.

```tsx
// TypeScript knows exactly what props are available
const T = createT(THREE)

// ✅ Fully typed with autocomplete
<T.PerspectiveCamera
  fov={75}                    // number
  aspect={window.innerWidth / window.innerHeight}  // number
  near={0.1}                  // number
  far={1000}                  // number
  position={[0, 0, 5]}        // [number, number, number]
/>
```

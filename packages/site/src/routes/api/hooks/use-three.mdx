# useThree

Provides access to the `three.js` context, including the renderer, scene, camera, and more. This hook can be used with or without a selector function for optimized access to specific properties.

> **Performance**: Use selector functions to avoid unnecessary re-renders when only specific properties are needed.

> **Stack Management**: Cameras and raycasters use a stack system for temporary overrides that automatically restore previous values.

## Context Properties

| Property | Type | Description |
|----------|------|-------------|
| **bounds** | `Measure` | Reactive canvas bounds measurement |
| **camera** | `Camera` | The current active camera |
| **setCamera** | `Function` | Push camera to stack (returns cleanup) |
| **canvas** | `HTMLCanvasElement` | The canvas DOM element |
| **clock** | `Clock` | THREE.js clock for timing |
| **dpr** | `number` | Device pixel ratio |
| **gl** | `WebGLRenderer` | WebGL renderer instance |
| **raycaster** | `Raycaster` | Current raycaster for events |
| **setRaycaster** | `Function` | Push raycaster to stack (returns cleanup) |
| **render** | `Function` | Manually trigger a render |
| **requestRender** | `Function` | Request render on next frame |
| **scene** | `Scene` | The root scene |
| **xr** | `Object` | WebXR connection management |

## Camera and Raycaster Stack System

`solid-three` implements a stack-based system for managing its current camera and raycaster:

- **Stack-based Management**: Both cameras and raycasters are managed as stacks internally
- **Default at Tail**: The `defaultCamera` and `defaultRaycaster` from Canvas props form the tail of their respective stacks
- **Current Active Camera at Head**: The camera/raycaster at the top of the stack is the currently active camera/raycaster
- **Push To The Stack To Become Active**: By calling `setCamera(camera)` and `setRaycaster(raycaster)`, the camera/raycaster is pushed to the stack. This causes it to become the currently active camera/raycaster
- **Pop From The Stack To Deactivate**: `setCamera(camera)` and `setRaycaster(raycaster)` return a cleanup-function to pop the camera/raycaster from the stack. If the camera/raycaster was on top of the stack, the previous camera/raycaster in the stack becomes active again

## Usage Patterns

```tsx tab title="Basic Access"
// Access full context
const three = useThree()

createEffect(() => {
  console.log("Canvas size:", three.bounds.width, three.bounds.height)
  console.log("Current camera:", three.camera)
  console.log("WebGL renderer:", three.gl)
})
```

```tsx tab title="Selective Access (Performance)"
// Only access specific properties for better performance
const camera = useThree(state => state.camera)
const { gl, scene } = useThree(state => ({ 
  gl: state.gl, 
  scene: state.scene 
}))

// This component only re-renders when camera changes
function CameraInfo() {
  const camera = useThree(state => state.camera)
  return <div>Camera: {camera.type}</div>
}
```

```tsx tab title="Camera Stack Management"
// Temporary camera switching with automatic restoration
function TemporaryCameraSwitch() {
  const three = useThree()
  const [useOrtho, setUseOrtho] = createSignal(false)

  createEffect(() => {
    if (useOrtho()) {
      const orthoCamera = new OrthographicCamera(-5, 5, 5, -5, 0.1, 1000)
      orthoCamera.position.set(0, 0, 5)

      // Push ortho camera onto stack
      const restore = three.setCamera(orthoCamera)

      // Cleanup automatically restores previous camera
      onCleanup(restore)
    }
  })
  
  return (
    <button onClick={() => setUseOrtho(!useOrtho())}>
      {useOrtho() ? "Use Perspective" : "Use Orthographic"}
    </button>
  )
}
```

```tsx tab title="Manual Rendering Control"
// For frameloop="demand" or custom render timing
function ManualRenderControl() {
  const three = useThree()
  
  const triggerRender = () => {
    // Request a single render on next frame
    three.requestRender()
  }
  
  const manualRender = () => {
    // Manually render with specific delta time
    three.render(0.016) // 16ms delta
  }
  
  return (
    <>
      <button onClick={triggerRender}>Request Render</button>
      <button onClick={manualRender}>Manual Render</button>
    </>
  )
}
```
